# Concept renders

`catalog-toys-concept-render-v1.png` is an AI-generated, isometric **concept visualization** for four catalog-parts toy directions: Pinball Lab, Cable-Car Dash, Gear Garden, and Springy Wobblebot.

It is intentionally not an engineering drawing, an exact CAD assembly, or a statement that every visible component maps to the current BOM. Refer to [the no-fabrication build standard](../../docs/BUILD_STANDARD.md) before using a visual to plan a purchase or workshop.
